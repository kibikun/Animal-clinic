# Animal-clinic  
  
A website for an animal clinic, designed to provide essential information about veterinary services while creating a warm and welcoming experience for pet owners.  

## Overview

The Animal Clinic website is built to represent a professional veterinary service that prioritizes pet health, comfort, and care. It features a clean layout, user-friendly navigation, and a design that reflects trust and compassion.

## Live Demo

https://kibikun.github.io/Animal-clinic/

## Features  

- Responsive design (mobile-friendly)
- Clean and modern UI
- Smooth scrolling navigation
- Informative sections (About, Services, Contact)
- Engaging hero section
- Easy-to-read layout for users
